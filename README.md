```

├── public/

├── api/
│   └── chat.js            ← Vercel サーバーレス関数（APIキーを秘匿）

```

## ⚠️ デプロイ前に必ず確認・変更してほしいこと

1. **予約URLについて**：現在は「電話＋公式LINEのみ」で案内する設計にしています。今後オンライン予約サイトを導入される場合は、`public/index.html` 内の `SYSTEM_PROMPT`（【予約案内】の節）と `SALON` オブジェクトを更新してください。
2. **LINEリンクの確認**：`https://line.me/R/ti/p/@dle3534c` を暫定で設定しています。LINE公式アカウントの「友だち追加URL」は管理画面で正式なものを発行できますので、念のため実際にタップして正しく友だち追加できるかご確認ください。
3. **縮毛矯正メニューについて**：よくある質問には「縮毛矯正」についての回答がありますが、メニュー一覧（Q11の表）には縮毛矯正の料金記載がありませんでした。縮毛矯正メニューを扱っている場合は、料金・所要時間を教えていただければ `MENU` 配列に追加します。
4. **`ANTHROPIC_API_KEY` の設定**：Vercel／Netlifyの環境変数に設定してください（下記手順参照）。既存の他サロン様チャットボットと同じAPIキーを使い回すことも可能ですが、利用量の切り分けをしたい場合は [console.anthropic.com](https://console.anthropic.com) で新しいキーを1本発行するのが簡単です。
5. **使用モデル名の確認**：現在 `claude-sonnet-4-5-20250929` を指定しています。最新の推奨モデル名は [docs.claude.com](https://docs.claude.com) でご確認のうえ、必要であれば `public/index.html` 内の `sendMessage` 関数内の `model` の値を差し替えてください。
6. **営業時間外判定について**：`isWithinBusinessHours()` 関数は「火曜定休」のみを自動判定しています。第3月曜の定休日は日付が毎月変わるため自動判定に含めていません。厳密な判定が必要であれば、カレンダー連携（Googleカレンダー連携）と合わせて実装するのがおすすめです（下記「今後の拡張候補」参照）。

## デプロイ手順

### Vercel（メイン）
1. GitHubリポジトリを新規作成し、このフォルダの中身をすべてプッシュ
2. [vercel.com](https://vercel.com) でGitHubリポジトリをインポート
3. プロジェクト設定 → Environment Variables で `ANTHROPIC_API_KEY` を設定
4. デプロイ完了（GitHubへのpushで自動デプロイされます）

### Netlify（バックアップ）
1. [app.netlify.com](https://app.netlify.com) で同じGitHubリポジトリを接続
2. Site settings → Environment variables で `ANTHROPIC_API_KEY` を設定
3. デプロイ完了（自動）

※ APIキーの値そのものは絶対にチャットやコードに直書きせず、必ずVercel/Netlifyの管理画面から設定してください。

## トラブルシューティング

| 症状 | 原因 | 解決策 |
|---|---|---|
| 画面が真っ白 | BabelのJSXがimport文を生成してしまっている | `index.html` の `<script>` タグの `onload` 設定（classicモード指定）が保持されているか確認 |
| チャットが応答しない（Vercel） | `ANTHROPIC_API_KEY` 未設定 | Vercelの環境変数を確認・再デプロイ |
| チャットが応答しない（Netlify） | `netlify.toml` のリダイレクト設定漏れ | `/api/*` → `/.netlify/functions/:splat` が設定されているか確認 |
| APIキーが漏れる恐れ | フロントエンドに直書きしてしまっている | 必ず `api/chat.js`（サーバー関数）経由でAPIを呼び出す構成のままにする |
